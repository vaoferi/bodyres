# Дизайн 5: Сучасний мінімалізм

## Концепція
Чистий, сучасний дизайн з акцентом на типографіку та geometric shapes. Professional, minimalist, memorable.

## Кольорова палітра
| Роль | Колір | HEX |
|------|-------|-----|
| Primary | Чорний | `#000000` |
| Secondary | Білий | `#FFFFFF` |
| Accent | Яскравий помаранчевий | `#FF5722` |
| Background | Чистий білий | `#FAFAFA` |
| Text | Чорний | `#111111` |
| Muted | Сірий | `#888888` |

## Типографіка
- **Заголовки:** Space Grotesk — геометричний, сучасний
- **Текст:** IBM Plex Sans — технічний, чистий
- **Моно:** IBM Plex Mono — для номерів телефонів

## Layout
```
[Hero - 50/50 split: текст + геометрія]
[Послуги - нумерований список з описами]
[Про мене - картка з фото, мінімалістична]
[Результати - before/after слайдер]
[Відгуки - прості картки з фото]
[CTA - чорний блок, контраст]
[Контакти - мінімальні,电话号码 prominent]
```

## Компоненти
- Hero: split layout, geometric accent shapes
- Послуги: нумеровані блоки, мінімум декорацій
- Кнопки: чорний фон, hover orange
- Геометрія: тонкі лінії, кола як акценти

## Настрій
Professional, efficient, trustworthy, modern healthcare aesthetic.

## Анімації
- Геометричні елементи рухаються при скролі
- Hover на посиланнях: underline slide-in
- Числа morph при появі

## Шрифтові розміри
- H1: 72px / 80px bold (desktop), 40px / 48px (mobile)
- H2: 28px / 36px semibold
- Body: 16px / 26px
- Phone: 24px / 32px mono
