# Дизайн 2: Преміум-люкс

## Концепція
Елегантний, розкішний дизайн для клієнтів high-end сегменту. Темні акценти, золоті деталі, атмосфера exclusivity.

## Кольорова палітра
| Роль | Колір | HEX |
|------|-------|-----|
| Primary | Глибокий чорний | `#1A1A1A` |
| Secondary | Золотий | `#C9A962` |
| Accent | Мідний | `#B87333` |
| Background | Кремовий | `#FAF7F2` |
| Text | Темний | `#1A1A1A` |
| Light text | Світло-сірий | `#E8E4DE` |

## Типографіка
- **Заголовки:** Playfair Display (serif) — розкішний, класичний
- **Текст:** Inter — сучасний, читабельний
- **Акцент:** Cormorant — для підписів

## Layout
```
[Hero - темний фон, золотий текст, центрований]
[Лінія - золота, тонка]
[Послуги - 2 колонки, великі картки]
[Про мене - фото + текст, асиметричний]
[Відгуки - вертикальні картки з фото]
[CTA - темний блок, золота кнопка]
[Футер - контакти, мінімалістичний]
```

## Компоненти
- Hero: повноекранний темний фон з subtle текстурою
- Картки: темний фон, золотий border при hover
- Кнопки: золотий градієнт, hover затемнення
- Розділювачі: тонкі золоті лінії

## Настрій
Розкіш, ексклюзивність, персоналізований сервіс, premium quality.

## Анімації
- Parallax на зображенні hero
- Gold shimmer ефект на кнопках
- Fade-in слайд для секцій

## Шрифтові розміри
- H1: 64px / 72px (letter-spacing: 0.02em)
- H2: 42px / 52px
- Body: 17px / 28px
- Quote: 24px / 36px italic
