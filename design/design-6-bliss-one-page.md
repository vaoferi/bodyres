# Дизайн 6: Bliss one-page

## Статус
Архівний варіант. Дивись `design-7-sharp-main-file.md` як активний напрямок для BodyRes.

## Концепція
One-page лендинг у дусі Bliss HTML5 Template: структурований, щільний, з акуратним класичним ритмом, але без демо-контенту, QR-плакатів і зайвого порожнього простору.

- Готові блоки й композиційні патерни: `/mnt/synology/BodyRes/Elements/Bliss - HTML5 Template`
- Реальні фото: локальні `photo_*.jpg` у корені проєкту

- Адресу: `Одеса, Фонтанська дорога, 58/3`

- Підказку про попередній запис
- Блок про відчуття після перших сеансів
- Фінальний заклик до консультації
- Соціальні іконки замість QR-постерів

## Spacing mode
`Fibonacci` для landing / marketing rhythm.

## Візуальний напрям
- Теплий білий фон
- Корал і бірюза як акценти
- Щільні картки без “дір”
- Більш класичний, зібраний ритм, як у Bliss template

## Layout
```
[Header - logo + nav + телефон]
[Hero - сильний headline + фото + social icons]
[Services - 10 щільних карток послуг]
[Results - ефекти після сеансів]
[Approach - чому приходять]
[CTA - короткий сильний заклик]
[Contacts - адреса, телефон, route link, social icons]
[Footer - copyright + back-to-top]
```

## Компоненти
- Hero: зібраний двоколонковий вступ, без порожньої сцени
- Services: сітка карток з outcome та tag
- Results: реальні наслідки після курсів
- Contacts: адреса, телефон, маршрут/route link, соціальні іконки без QR
- Footer: простий, акуратний, без додаткового шуму

## Що не робити
- Не вставляти QR-коди картинками в основний UI
- Не будувати сторінку на декоративних текстових зображеннях
- Не залишати великі порожні поля без змісту
- Не ламати one-page логіку multipage переходами

## Настрій
Зібраність, рух, турбота, ясність, відчутний результат без візуального сміття.
