## Layout
```
[Header - logo + nav + телефон]
[Hero - сильний headline + фото кабінету + social icons]
[Services - 10 щільних карток послуг]
[Results - ефекти після сеансів]
[Approach - чому повертаються]
[Gallery / CTA - фото + швидкий запис]
[Contacts - адреса, телефон, route link, social icons]
[Footer - copyright + back-to-top]
```

## Компоненти
- Hero: двоколонковий вступ із великим serif-заголовком, фото і нижнім контактним баром
- Services: щільна grid-сітка з 10 картками, номером, outcome і коротким описом
- Results: список реальних наслідків після курсів
- Gallery / CTA: візуальний блок з фото та прямим записом
- Contacts: адреса, телефон, маршрут/route link і соціальні іконки без QR
- Footer: темний, структурований, з чітким копірайтом

## Що не робити
- Не вставляти QR-коди картинками в основний UI
- Не будувати сторінку на декоративних текстових зображеннях
- Не залишати великі порожні поля без змісту
- Не змішувати цей варіант із energy-motion пастеллю

## Настрій
Зібраність, довіра, рух, чіткість, якість, відчутний результат без візуального сміття.
