# Дизайн 4: Теплий дім

## Концепція
Затишний, домашній дизайн. Створює відчуття турботи, комфорту, прийняття. М'які тони, organic shapes.

## Кольорова палітра
| Роль | Колір | HEX |
|------|-------|-----|
| Primary | Теплий беж | `#D4A574` |
| Secondary | Оливковий | `#8B9A6D` |
| Accent | Терракот | `#C67B5C` |
| Background | Кремовый | `#F8F4F0` |
| Text | Темно-коричневий | `#3D3229` |
| Light | Світлий беж | `#EDE5DC` |

## Типографіка
- **Заголовки:** Lora (serif) — теплий, затишний
- **Текст:** Source Sans Pro — чистий, дружній
- **Акцент:** Dancing Script — для цитат/закликів

## Layout
```
[Hero - фото з теплим фільтром, overlay]
[Привітання - особистий текст, фото майстра]
[Послуги - органичні картки, різні розміри]
[Процес - таймлайн кроків]
[Відгуки - картки з м'якими кутами]
[CTA - теплий gradient]
[Контакти - адреса, телефон, години]
```

## Компоненти
- Hero: organic shape overlay, warm tones
- Картки: border-radius: 20px, soft shadow
- Секція процесу: timeline з крапками
- Кнопки: organіc shape, warm gradient

## Настрій
Турбота, комфорт, довіра, домашній затишок, personalized care.

## Анімації
- Плавне розкриття секцій (fade + slide)
- Organic blob shapes parallax
- М'які hover ефекти на картках

## Шрифтові розміри
- H1: 52px / 60px
- H2: 34px / 44px
- Body: 18px / 30px
- Script: 28px / 40px
