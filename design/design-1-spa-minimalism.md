# Дизайн 1: SPA-мінімалізм

## Концепція
Спокійна, чиста атмосфера з акцентом на розслаблення та благополуччя. Білий простір, м'які тони, багато повітря.

## Типографіка
- **Заголовки:** Cormorant Garamond (serif) — елегантний, спокійний
- **Текст:** Nunito Sans — м'який, читабельний
- **Акцент:** Playfair Display — для цитат

## Layout
```
[Hero - повноекранне фото з туманним ефектом]
[Послуги - картки з іконками, 3 колонки]
[Переваги - горизонтальна лінія з точками]
[Відгуки - слайдер]
[CTA секція - мінімалістична]
[Контакти + карта]
```

## Компоненти
- Hero: напівпрозорий градієнт, центрований текст
- Картки послуг: білий фон, м'ятна іконка, hover-підйом
- Кнопки: заокруглені, тіні приховані, border на ховер
- Секції: розділені тонкими лініями або відступами

## Настрій
Релакс, чистота, простір, спокій. Асоціації: SPA-салон, yoga-studio, wellness.

## Анімації
- Плавне fade-in при скролі (400ms ease-out)
- Hover на картках: translateY(-4px)
- Паралакс на hero-зображенні

## Шрифтові розміри
- H1: 56px / 64px line-height
- H2: 36px / 44px
- Body: 18px / 28px
